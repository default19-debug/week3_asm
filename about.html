About Us

This site was built as a Week 3 assignment for COS30049 Computing Technology Innovation Project, demonstrating HTML structure, external CSS styling, vanilla JavaScript interactivity and version control with a GitHub repository.

🎯

Our purpose

To make appliance energy use easier to interpret by converting power ratings into the kilowatt-hours and dollar figures that actually appear on a household electricity bill.

👤

Who built it

Designed and developed by Tri Tran, a Computer Science student at Swinburne University of Technology, as an individual assignment submission.

🛠

How it was built

Hand-written HTML, a single external CSS stylesheet and vanilla JavaScript. No frameworks, build tools or third-party libraries are used anywhere on the site.

What this site demonstrates

  • Semantic HTML across three linked pages with a shared header and footer.
  • External CSS in a single stylesheet, with a palette sampled directly from the site logo.
  • Responsive layout built with CSS Grid and Flexbox, tested down to small phone widths.
  • Navigation states including a hover effect, an active-page indicator and a logo that links home.
  • JavaScript interactivity in the FAQ accordion and the appliance energy calculator.
  • Input validation with clear, user-friendly messages shown beside each field.
  • Accessibility through ARIA attributes, keyboard focus styles and a skip link.
  • Version control with the project tracked in a public GitHub repository.
